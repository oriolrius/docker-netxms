## v1.1.0 (2026-08-18)

- Pin the NetXMS packages in both images to a fixed version (`NETXMS_VERSION`,
  default 6.2.3) so a rebuild no longer silently upgrades NetXMS — which for the
  server meant a crash loop against an existing database. `NETXMS_VERSION=latest`
  restores the previous behaviour.
